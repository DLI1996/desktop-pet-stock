Safe exchange checklist

  1. Choose an authoritative/licensed provider and document its contract.
  2. Define an exchange-qualified symbol, never infer ambiguous bare codes globally.
  3. Parse provider data into QuoteResult behind an adapter.
  4. Use exchange timezone, sessions, holidays, and delayed-data semantics.
  5. Add fixture-based parser, symbol, calendar, fallback, and stale-data tests.
  6. Label source and realtime/delayed/closed status accurately in the UI.
  7. Make external browser/app/file actions opt-in before broader distribution.

Risk boundaries

  • Data integrity: malformed or stale quotes can produce a wrong pet state.
  • Desktop side effects: SURGE opens a website; FALL launches WPS or writes a document.
  • Privacy: provider requests expose the watched symbol and IP address to the provider.
  • Supply chain: dependencies are lower-bounded, not locked or hash-pinned.
  • Licensing: bundled character art/audio needs permission for redistribution or commercial use.
